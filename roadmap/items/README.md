# Roadmap Item Docs

Use this directory for one document per roadmap item from `roadmap/roadmap.md`.

Naming convention:
- `p0-short-item-slug.md`
- `p1-short-item-slug.md`
- `p2-short-item-slug.md`

Recommended sections:
- Summary
- Scope
- Out of Scope
- Acceptance Criteria
- Test Plan
- Risks and Dependencies
- Notes
